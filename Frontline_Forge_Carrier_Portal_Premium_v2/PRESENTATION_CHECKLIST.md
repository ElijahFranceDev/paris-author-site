## Before presenting

- Run the SQL upgrade successfully.
- Run `npm install` and `npm run build`.
- Deploy with `npx vercel --prod`.
- Verify `CRON_SECRET` exists in Vercel.
- Email delivery is optional for the demo. In-app notifications work without Resend.
- Do not display Supabase secret keys, Vercel environment variables, or temporary passwords on screen.
